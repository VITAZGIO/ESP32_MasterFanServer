# ESP32_MasterFanServer

Контроллер на **ESP32-C3 mini** для управления охлаждением и питанием домашнего сервера через **Home Assistant** (по MQTT).

ESP отвечает за регулировку оборотов корпусных кулеров, чтение температуры, мониторинг оборотов всех вентиляторов, определение статуса сервера (вкл/выкл) и эмуляцию нажатия кнопки питания.

---

## Возможности

- Регулировка скорости двух корпусных кулеров (впускной + выпускной), уровни 1–10
- Общее управление (оба кулера разом) и раздельное (каждый отдельно)
- Чтение оборотов (RPM) трёх вентиляторов: впускной, выпускной, башенный CPU-кулер
- Датчик температуры DS18B20 возле HDD
- Определение статуса сервера по линии Power LED (включён / выключен)
- Эмуляция кнопки Power через оптопару: короткое нажатие и удержание (для жёсткого выключения)
- Включение/выключение питания обоих кулеров через MOSFET → реле
- Подробная диагностика в монитор порта раз в 10 секунд
- Детальный лог подключения WiFi и MQTT с расшифровкой ошибок

## Распиновка (ESP32-C3)

| GPIO | Назначение | Примечание |
|------|-----------|-----------|
| GPIO2  | FAN1 TACH (впускной) | подтяжка INPUT_PULLUP |
| GPIO3  | FAN2 PWM (выпускной) | через BC547, инверсный |
| GPIO4  | FAN1 PWM (впускной) | через BC547, прямой |
| GPIO5  | FAN2 TACH (выпускной) | подтяжка INPUT_PULLUP |
| GPIO6  | DS18B20 (температура HDD) | подтяжка 4.7k к 3.3В |
| GPIO7  | POWER BUTTON (оптопара) | импульс = нажатие |
| GPIO8  | POWER LED detect | делитель 10k/10k, вход |
| GPIO10 | MOSFET → реле (питание кулеров) | LOW = вкл, HIGH = выкл |
| GPIO1  | CPU TACH (башенный кулер) | НЕ ставить на 20/21 (UART) |

> **Важно:** GPIO20 и GPIO21 — это UART0 (монитор порта). Тахометры на них вешать нельзя — мешают логу и сбивают счёт. CPU TACH вынесен на GPIO1.

## MQTT-топики

Префикс: `serverfan/`

### Управление (подписка, set)

| Топик | Значения | Действие |
|-------|----------|----------|
| `fan/power/set` | `ON` / `OFF` / `TOGGLE` | питание обоих кулеров (реле) |
| `fan/speed/set` | `1`–`10` | общий уровень — ставит ОБОИМ кулерам |
| `fan1/speed/set` | `1`–`10` | уровень только впускного кулера |
| `fan2/speed/set` | `1`–`10` | уровень только выпускного кулера |
| `server/power_button/press` | `PRESS` / `HOLD_5000` / `HOLD_<мс>` | нажатие кнопки питания сервера |

### Состояние (публикация, state)

| Топик | Содержимое |
|-------|-----------|
| `status` | `online` / `offline` (LWT) |
| `fan/power/state` | `ON` / `OFF` |
| `fan/speed/state` | текущий общий уровень |
| `fan1/speed/state` | уровень впускного |
| `fan2/speed/state` | уровень выпускного |
| `fan/pwm/state` | текущее значение PWM |
| `fan1/rpm/state` | обороты впускного |
| `fan2/rpm/state` | обороты выпускного |
| `cpu/rpm/state` | обороты башенного CPU-кулера |
| `temp/hdd/state` | температура у HDD, °C |
| `server/state` | `ON` / `OFF` (по Power LED) |

## Логика работы

- **Уровни скорости 1–10** маппятся на PWM по таблице `FAN_SPEED_PWM`. 1 = тихо, 10 = максимум.
- **Кулеры разных моделей** реагируют на PWM по-разному, поэтому у FAN2 включена инверсия (`FAN2_INVERTED = true`). Если кулер крутит наоборот — поменять флаг `FAN1_INVERTED` / `FAN2_INVERTED` вверху скетча.
- **Кнопка Power** даёт импульс на оптопару: 500 мс по умолчанию (короткое нажатие), `HOLD_5000` — удержание 5 сек для принудительного выключения.
- **MOSFET/реле** — только вкл/выкл питания кулеров, без PWM (реле механическое, частить нельзя).

## Диагностика

Раз в 10 секунд в монитор порта (115200) выводится блок:

- статус WiFi + IP + RSSI (сила сигнала, ближе к 0 = лучше)
- статус MQTT с расшифровкой ошибки
- статус сервера по Power LED
- обороты всех трёх вентиляторов
- температура HDD
- аптайм и свободная память

При проблемах со связью лог подключения показывает, на каком этапе затык (WiFi не найден / неверный пароль / брокер недоступен / неверные креды и т.д.).

## Известные нюансы

- **GPIO8 (Power LED)** — strapping-пин. Если ESP иногда не грузится при включённом сервере — причина может быть в уровне на этом пине в момент старта.
- **GPIO7 (кнопка Power)** — после аварии с перегревом на старом GPIO8 был слабый сигнал (1.6 В вместо 3.3 В). Кнопка перенесена на GPIO7. Если перестанет срабатывать — проверить напряжение на пине при нажатии.
- **CPU TACH на GPIO1** — если показывает 0 при крутящемся кулере, поменять пин на 0 или 9 (свободные), но не на 20/21.
